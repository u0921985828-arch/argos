Captura

Apoya el dispositivo en algo fijo. Todo el análisis asume vista estática: si la cámara se mueve, la escena entera se detecta como objeto.

Región

Arrastra el recuadro sobre el vídeo que quieras analizar y ajústalo con las esquinas. Solo se analiza lo de dentro.

Al mover el recuadro se reinicia el modelo de fondo: la escena de debajo es otra. Ajústalo antes de empezar a grabar.

Detector

Ahora mismo: sustracción de fondo. Encuentra lo que se mueve, y eso basta para tráfico — pero una multitud densa y parada es, para un modelo de fondo, parte del fondo.

Recorta teselas más pequeñas y las amplía antes de mirarlas. Una persona de 20 px llega al modelo a 40. Coste: al doble de zoom, cuatro veces más teselas.

Pesos Apache-2.0 de YOLOX. El modelo se ejecuta aquí con ONNX Runtime Web: no sale nada del equipo.

Vista

La capa de siluetas es anónima por construcción: lleva postura, marcha, clase, tamaño y posición, y nada del detalle facial o de ropa que convierte una imagen en dato personal.
